## DESCRIPTION

### The Problem

Retail crypto investors lose **$4.6 billion annually** to:
- Honeypot scams (can buy, can't sell)
- Rug pulls (developers drain liquidity)
- Hidden taxes (20-99% on transactions)
- Fake tokens impersonating legitimate projects

Existing tools are either too technical, incomplete, or don't explain WHY a token is risky.

### The Solution

AIDYOR provides **instant, AI-explained security analysis** for any cryptocurrency token:

1. **Paste any token address** → Get a 0-100 safety score in seconds
2. **AI explains the risks** → Plain English, not technical jargon
3. **Multi-source verification** → 7 APIs cross-referenced
4. **Unique features** → OCR scanning, whale alerts, push notifications
